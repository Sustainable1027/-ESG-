  Repository Overview

This repository provides the principal replication materials for the study “Do Environmental, Social, and Governance Domains Relate Differently to Firm Performance? Evidence from a Meta-Analytic Structural Equation Model.” It supports inspection of the included evidence base and replication of the principal structural and sensitivity analyses reported in the paper. The materials are organized into three folders covering the included literature, the main meta-analytic structural equation modeling (MASEM) analysis, and robustness checks.

Folder Structure and Description

1. Meta-Analysis Literature List
This folder contains the study-level master literature database for the meta-analysis described in Sections 3.1–3.4. The database documents the final evidence base identified through the screening procedure in Section 3.2. Each included study is assigned a Research ID to support study-level tracking.
The database records core bibliographic information, including authorship, publication outlet, and publication year. The final sample comprises 283 quantitative empirical studies that contributed at least one eligible correlation to the 36-cell meta-analytic correlation matrix. These records allow readers to inspect the composition of the included evidence base.
2. Main MASEM Analysis
This folder contains the files used for the structural analysis described in Section 3.5, including:
- the pooled meta-analytic correlation matrix;
- executable Mplus input files specifying the correlation-based MASEM; and
- model output files reporting path estimates, model-fit statistics, and explained variance.
The model jointly estimates the conditional associations of the environmental, social, and governance domains with financial performance, market value, and innovation output. It includes firm size, firm age, and leverage as controls and retains the correlations among the ESG domains and the other predictors. The supplied pooled matrix and Mplus files support replication of the structural-model results reported in Fig. 3 and Tables 2–3.
3. Robustness Checks
This folder contains analytical materials supporting the sensitivity and publication-bias assessments reported in Section 4.4. These materials relate to:
- assessment of influential estimates using the Sample-Adjusted Meta-Analytic Deviancy (SAMD) statistic and structural-model re-estimation after their removal; and
- publication-bias diagnostics, including Egger’s regression test, Rosenthal’s fail-safe N, and Trim-and-Fill procedures.
The folder includes the matrices used to re-estimate the structural model for the reported sensitivity checks. These analyses assess whether influential estimates or potential small-study effects materially alter the principal comparative domain-to-outcome pattern. They are sensitivity diagnostics and do not independently validate the underlying data or analytical decisions of the primary studies.

Replicability and Data Availability

The public repository provides the included-study literature database, pooled correlation matrices, Mplus input and output files, and the matrices used for the influence and publication-bias checks. These materials allow readers to inspect the included evidence base and replicate the principal structural and sensitivity analyses reported in the paper using the supplied pooled matrices and analytical files.
The full effect-size extraction file and coding protocol are retained by the authors and are available from the corresponding author on reasonable request, as stated in the manuscript’s Data Availability Statement. Re-estimation of the first-stage pooled correlations requires the full effect-size extraction file.
The repository does not redistribute copyrighted full texts or the underlying firm-level data used by the primary studies.
